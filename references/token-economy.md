# Token 经济（详表）

规范支柱在执行面由 `SKILL.md` 短摘录；**本文件 = 详表**（自 PLAN §14.14）。执行任务勿加载 `PLAN.md`；需要成本账 / 分流 / 可瘦禁砍时读本文件。

## 成本账

| 贵在哪 | 换来什么 | 更贵的失败 |
|--------|----------|------------|
| 写四件套 + 读链路 | 可审 Map、可复现证据、可续跑状态 | 改错层 / 漏触点后的第二轮 |
| 人等 Map 完成再改 | 范围不膨胀 | 顺手重构整文件 |
| 落盘占用写工具调用 | 跨会话不靠聊天记忆 | 新会话从零考古 |

落盘：闸门状态外置到 `.delegate/<slug>/` → 人审 + 续跑读盘 + check 验盘。**续跑/暖启动摊薄的是后续会话**，不否认首跑更贵。

## 分流（何时付全价）

| 路径 | 条件 | Token 含义 |
|------|------|------------|
| **黑名单 / 退出** | typo、纯解释、粘贴补丁等 | 最省：不建或 abort，禁止空转协议 |
| **Fast path** | 用户点名文件/符号 + 意图 | 短 map；Change/证据仍付费 |
| **全 Map** | 陌生 / 跨层 / 要留痕 | 付全价；产品主场 |
| **investigate_only** | 只摸清不改 | 付 Map，不付改码与假完成 |
| **续跑** | 同 slug 未完成 | 读盘接着，禁止凭聊天跳步 |
| **验收追诉** | 同 slug 刚 done，用户追同控件未收口 | 重开同 slug + 追加证据；勿新开目录空转 |
| **暖启动** | 新 slug + 仓内近邻产物 | 只摘触点/边界作线索；不免 Map |

```text
误用拦截 → 任务分流 → 会话间复用（续跑/暖启动） → 仪式变瘦
```

## 可瘦 vs 禁砍

| 可瘦（仪式 / 密度） | 禁砍（产品定义） |
|--------------------|------------------|
| `onboard` 长篇「为什么」（非用户要求时用 `delegate`） | Map 未 `complete`（无合法 fast path）禁止改业务代码 |
| 可选 Git 线索整段跳过 | 证据 ≥ L1 才可宣称 done；验证含可复现步骤/前/后 |
| 对用户回复里重复粘贴已落盘全文 | 触点列表 + 改动边界（短 map 也要） |
| 一次塞多份旧 `map.md` 全文 | 产物落盘四件套（可中途 `--draft`，不可无盘宣称 done） |
| 小任务硬开全 Map（应走黑名单或 Fast path） | 范围膨胀时回 Map + CHECKPOINT，不闷头扩改 |
| 执行时加载 `PLAN.md` 全文 | check 脚本 `RESULT: OK` 前的完成闸门 |

## 实现约束

1. **SKILL 保持瘦**：支柱进 SKILL 时 ≤8 行 + 指针；表放本文件。
2. **禁止**用「省 token」作为 `fast_path: true` 或 Map `complete` 的理由；Fast path 唯一合法来源仍是用户点名文件+意图（或用户在暖启动中**明确确认**走 fast path）。
3. **测量**：eval 对比「误用是否退出 / Fast path 是否仍有短 map+L1」，**不**要求总 token 低于裸改。
4. 质量仍靠人审 Map 实质；脚本只反 stub，不替代判断。
5. 维护刀合并前自检：可审计与 Token 经济两支柱同级，不可为省上下文拆闸门。
